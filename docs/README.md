## Authority and status

These documents define the intended protocol and governance model. They do not create technical integrations, authenticate AI systems, grant repository permissions, or prove that a runtime is connected.

Implementation status must be established independently from inspectable code, execution logs, test results, and versioned evidence.

## Update procedure

1. Inspect the source repository and current state.
2. Propose a documentation or artifact change.
3. Preserve source references and provenance.
4. Validate schema and links.
5. Obtain human approval for governance changes or privileged actions.
6. Publish through a traceable Git commit.
7. Re-check the published artifact and record the resulting revision.
